Course Platform - Detailed Module Requirements
1. User Roles
User (Student)
• Register/Login (Phone + OTP or Email) / Logout
• Manage profile
• View teachers and courses
• Purchase courses
• Access purchased courses
• Rate and review completed courses

Teacher
• Apply for registration on the platform (Phone + OTP or Email)
• Profile is visible and active only after admin verification and approval
• Manage profile and upload courses (post-approval)
• Track student enrollment and feedback

Admin
• Verify and approve teacher applications
• Manage users, teachers
• View payments
• Manage teachers and courses 
• Handle student queries and reports


2. Home Page Categories
Class 6, Class 7, Class 8, Class 9, Class 10, Class 11, Class 12, Banking, SSC, Railways,
UPSC, State PCS, Defence (Optional)

3. Category Selection Flow
Example: Banking → Subjects: Reasoning, English, Mathematics, General
Studies/General Awareness, Computer, Current Affairs (Optional).

4. Teacher Listing
Each teacher card displays Photo, Name, Qualification, Experience, Number of
Students, Rating, Total Reviews and a View Courses button.

5. Teacher Profile
Profile picture, introduction, qualification, experience, achievements, courses offered,
rating and student reviews.

6. Course Listing
Course Thumbnail, Name, Description, Duration, Videos, Language, Price, Discount,
Rating, Total Students and Buy Now button.

7. Course Details Page
Detailed description, syllabus, demo videos, duration, lectures, language, validity,
price, discount and purchase option.

8. Course Purchase
Payment through UPI, Credit Card, Debit Card, Net Banking and Wallet. Purchased
courses appear automatically in the student's dashboard.

9. My Courses
Purchased Courses, Continue Learning, Progress, Completed Videos 
(future).

10. Video Player
HD Video, PDF/Notes Download, Playback Speed, Full Screen and Progress Saving.

11. Rating System
Students can give 1–5 star ratings after completing a course. Average ratings are
calculated automatically.

12. Review System
Students can write reviews that are visible to other students.

13. Teacher Rating
Teacher ratings are calculated based on all course ratings.

14. Search & Filters
Search by Teacher Name, Course Name, Subject and Category. Filters: Price, Rating,
Experience, Language, Latest and Popular.

15. Admin Panel
Manage Categories, Subjects, Teachers, Courses, Students, Orders, Payments & Payouts,
Reviews, Coupons, Banners, Notifications, Mock Tests, Reports and Analytics.

16. Student Dashboard
Profile, Purchased Courses, Wishlist, Progress Report, Reviews, Certificates, Purchase
History, Mock Test Results, and Settings.

17. Teacher Dashboard
Profile Management, Course Creation & Video Uploads, Live Class Scheduling,
Earnings & Revenue Reports, Payout Requests, and Enrolled Students List.

18. Mock Tests & Quizzes
MCQ Test series for competitive exams, timed quiz interface, instant result evaluation,
and detailed performance analytics (Rank, Marks, Time Taken).

19. Live Classes & Doubt Solving
Integration for Live streaming classes, real-time chat for doubt solving,
and automated recording of sessions.

20. Revenue & Payout System
Clear platform commission split, tracking earnings per course, and processing teacher withdrawal requests.

Overall User Flow
Home → Select Category → Select Subject → View Teachers → Select Teacher → View
Courses → Course Details → Purchase Course → Watch Videos / Attend Live Class / Take Mock Test → Rate & Review Course
